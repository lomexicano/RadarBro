# Radar Bro LiteMod for Minecraft 1.5.2

I basically ported RadarBro, a mod made by Cali Alec, to LiteLoader. All credits to him.

# Description
RadarBro gives you comfort by letting you know where nearby enemies and mobs are.
You can toggle mobs and players on and off to focus on only what you are looking for.
Default key to open mod settings ingame: "R"

# Installation
Drop the .litemod file in the mods folder. You must have LiteLoader installed in order to run this mod.
